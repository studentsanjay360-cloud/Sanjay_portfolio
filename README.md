# Sanjay T — Portfolio Website

A responsive personal portfolio website with a dark-blue theme.

## Included
- `index.html` — website content
- `style.css` — responsive styling
- `script.js` — mobile navigation and current year
- `resume.pdf` — add your own resume PDF with this exact filename to activate the download link

## Preview on your phone
1. Extract the ZIP file.
2. Open `index.html` in a browser, or upload the files to a hosting service such as GitHub Pages.
3. To publish with GitHub Pages, create a **public** repository named `sanjay-portfolio`, upload the files in this folder to the repository root, then open **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**, choose `main` and `/ (root)`, then save. Wait for the published link to appear in the Pages section.

## Personalize before publishing
- Replace the sample project cards with projects you have actually completed.
- Add certificate names and links in the Certifications section.
- Add your resume PDF as `resume.pdf`.
- The GitHub profile link was not provided, so it is not included yet.
- Review the displayed email address before publishing.
